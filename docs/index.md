# Thyme Framework

Thyme is a framework for WordPress block themes. It's built around the principles Roots/Acorn already sets up for the users, with some extra goodies like Post Type registration right from your theme.

## Features

- [Easy post type registration]({% link post-types.md %})
- [Easy options page registration]({% link options-pages.md %})
- [Easy block registration]({% link blocks.md %})
- [Easy component rendering]({% link components.md %})

## Getting started

Thyme boots up similar to the existing [Acorn bootup sequence](https://roots.io/acorn/docs/installation/#booting-acorn), with one extra thing. See [Getting Started]({% link getting-started.md %}) for the full instructions.
